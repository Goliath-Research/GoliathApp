# Domain types for workflow scope variables

The workflow engine stores opaque JSON in `wf.scope_variable.value_json`. Tagged domain objects, JSON Schemas, compiler helpers, and scope state machines are application-defined.

Canonical documentation: [https://github.com/Goliath-Research/GoliathO%6Dics](https://github.com/Goliath-Research/GoliathO%6Dics)
